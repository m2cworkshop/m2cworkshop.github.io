# From Models to Collectives — ICLR 2027

Website for **M2C: From Models to Collectives — Orchestration of LLMs and Agents**, an ICLR 2027 workshop on learning and evaluating how heterogeneous foundation models and agents collaborate as adaptive collectives.

The site is a dependency-free collection of responsive HTML, CSS, and JavaScript pages designed for direct deployment with GitHub Pages.

## Preview locally

Run a local server from this directory:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish with GitHub Pages

1. Push this repository to GitHub.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)` folder.

The `.nojekyll` file ensures the static files are served as written.
